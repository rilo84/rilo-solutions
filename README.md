# Rilo Solutions

En Next.js-app med App Router, klar för Vercel.

## Lokalt

```bash
npm install
npm run dev
```

Öppna sedan [http://localhost:3000](http://localhost:3000).

## Vercel

1. Lägg upp mappen i ett Git-repository.
2. Importera repot i Vercel.
3. Vercel hittar automatiskt Next.js och använder `npm run build`.
4. Lägg till er domän under **Settings → Domains**.

Byt ut kontaktadressen `hej@rilosolutions.se` i `app/page.jsx` innan publicering om den inte är den rätta.
